## Overview

SOVL: Fantasy Warfare Save is a save management utility for SOVL: Fantasy Warfare, providing save slot backup, campaign state editing, army roster management, and hero attribute adjustment. It reads the game's binary save format and presents editable fields in a clean interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SOVL Fantasy Warfare Save** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Save Slots** | Backup and restore individual campaign save slots |
| **Army Roster** | Edit unit composition and experience levels in the saved roster |
| **Hero Attributes** | Modify hero stats and equipped item data |
| **Campaign Flags** | View and toggle campaign progression flags and decision states |
